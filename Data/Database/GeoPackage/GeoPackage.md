#data-type #vector #raster #database #container

Open, SQLite-based geospatial container format.

[GeoPackage](https://www.geopackage.org/)

- Stores vector features, tile matrices, attributes, and extensions in one `.gpkg` file.
- Good modern replacement for many Shapefile use cases.
- Supported by QGIS, GDAL/OGR, GeoServer, ArcGIS, and many mobile/offline workflows.
- Not really a flat file in the simple-table sense: it is a single-file spatial database/container.
