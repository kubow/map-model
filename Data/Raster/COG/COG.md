Cloud Optimized GeoTIFF.

[Cloud Optimized GeoTIFF](https://cogeo.org/)

- GeoTIFF layout optimized for HTTP range reads.
- Lets clients and services read only the raster parts they need.
- Useful for web visualization, cloud-hosted imagery, DEMs, and raster analytics.
