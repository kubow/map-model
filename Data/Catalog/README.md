# Catalogs and Discovery

Catalogs describe geospatial assets and services so they can be found, searched, cited, and connected to processing tools. They are not the primary storage format for the data itself.

Use this section for metadata models, discovery portals, and catalog-like systems.

- [STAC](STAC/STAC.md) - spatiotemporal asset metadata, common for imagery, rasters, point clouds, and cloud-native assets.
- [JackDaw](JackDaw/JackDaw.md) - geospatial AI / decision-support catalog-like tool.

## Related catalog systems

- [GeoNetwork](https://geonetwork-opensource.org/)
- [Micka metadata catalog](https://micka.cenia.cz/)
- [Geonorge metadata catalog](http://www.geonorge.no/geonetwork/srv/no/main.home)

## When this is the right shelf

- Describes datasets rather than storing features.
- Keeps provenance, license, temporal extent, spatial extent, links, and service endpoints.
- Points to COG, GeoTIFF, GeoParquet, WMS, WFS, OGC API, tile, or download assets.
