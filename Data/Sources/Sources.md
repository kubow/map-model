# Geographic Data Sources

Sources are where geodata comes from: institutions, datasets, services, catalogs, and informal place lists. Keep this page as a source index; store actual curated point collections under [Places](../Places/README.md).

## Source types

- Provider - institution, project, or person publishing data.
- Dataset - a specific downloadable or queryable package.
- Service - WMS, WFS, WMTS, OGC API, tile service, or API endpoint.
- Catalog - metadata/discovery system pointing to many datasets or services.
- Place source - a book, web page, trip note, or list that mentions candidate places.
