#server #api #postgis

Lightweight feature service for PostGIS.

[pg_featureserv](https://github.com/CrunchyData/pg_featureserv)

- Publishes PostGIS tables and functions as web feature APIs.
- Useful when the source of truth is PostGIS and the service layer should stay small.
- Complements [pg_tileserv](pg_tileserv.md) for vector tile publishing.
