#server #tileset #postgis

Vector tile server for PostGIS.

[pg_tileserv](https://github.com/CrunchyData/pg_tileserv)

- Serves Mapbox Vector Tiles directly from PostGIS.
- Useful for dynamic vector tiles from database tables or SQL functions.
- Good pairing with MapLibre and PostGIS.
