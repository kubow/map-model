#javascript #analysis #geometry

JavaScript geospatial analysis library.

[Turf.js](https://turfjs.org/)

- Browser or Node.js functions for buffers, intersections, distances, nearest points, bbox operations, and GeoJSON processing.
- Useful for lightweight client-side GIS logic and preprocessing before display.
- Works naturally with Leaflet, OpenLayers, MapLibre, and GeoJSON APIs.
