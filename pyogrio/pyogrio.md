#python #vector #gdal

Fast vector I/O library using GDAL/OGR.

[pyogrio](https://pyogrio.readthedocs.io/)

- Reads and writes vector formats such as Shapefile, GeoPackage, GeoJSON, FlatGeobuf, and others.
- Often faster than Fiona for bulk vector data access.
- Used by GeoPandas as an I/O engine.
