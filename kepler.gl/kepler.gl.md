#javascript #visualization #analytics

Browser tool and library for exploratory geospatial visualization.

[kepler.gl](https://kepler.gl/)

- Useful for quickly exploring large point, trip, grid, and polygon datasets.
- Can be embedded as a React component or used as a standalone web app.
- Strong for interactive visual analytics rather than long-term data serving.
