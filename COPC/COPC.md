#point-cloud #format #cloud-native

Cloud Optimized Point Cloud.

[COPC](https://copc.io/)

- LAZ-based point cloud format organized for efficient HTTP range reads.
- Similar cloud-native idea to COG, but for point clouds.
- Useful for lidar and massive point cloud datasets.
