#point-cloud #lidar #tool

Point Data Abstraction Library.

[PDAL](https://pdal.io/)

- Command line and library tooling for point cloud processing.
- Reads and writes LAS, LAZ, EPT, COPC, and other point cloud formats.
- Useful for filtering, reprojection, rasterization, pipelines, and lidar ETL.
