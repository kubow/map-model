#server #raster #tileset #python

Dynamic tile service for Cloud Optimized GeoTIFF and other raster sources.

[TiTiler](https://developmentseed.org/titiler/)

- Builds web tile APIs around COGs and STAC assets.
- Useful for visualizing cloud-hosted rasters without pre-generating tile pyramids.
- Based on FastAPI and rio-tiler.
