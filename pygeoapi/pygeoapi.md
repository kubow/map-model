#server #api #python #ogc

Python server implementation of OGC API standards.

[pygeoapi](https://pygeoapi.io/)

- Publishes geospatial data using modern OGC API endpoints.
- Supports features, coverages, maps, tiles, records, processes, STAC, and environmental data retrieval depending on configuration.
- Lighter and more API-native than a classic GeoServer setup.
